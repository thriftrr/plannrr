# YNABRR — Nuxt app

See the [root README](../../README.md) for what this project is and the YNAB API cheat sheet.

## Setup

```sh
npm install
cp .env.example .env   # then add your YNAB personal access token
```

## Development server

Start on `http://localhost:3000`:

```sh
npm run dev
```

## Production

```sh
npm run build
npm run preview
```
